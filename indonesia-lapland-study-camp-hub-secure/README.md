# Indonesia–Lapland Study Camp Hub — GitHub Pages build

This is the simple static deployment version, matching the earlier BALAI CRM workflow.

## Deploy
1. Put `index.html` in the root of the GitHub repository.
2. Make the repository public if using standard GitHub Pages public hosting.
3. GitHub repository → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`; folder: `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Important
This version stores CRM records in each browser's localStorage. Data entered by one team member does not automatically sync to another user's browser.

The login screen is a front-end access gate, not strong security. Do not store confidential documents or sensitive personal information in this static build.
